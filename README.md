# Dashboard Todo App

*A modern, responsive dashboard application built with React, TypeScript, Vite, and Tailwind CSS. This application features a comprehensive task management system and user administration capabilities, designed with a focus on UI/UX using shadcn/ui components.*

<p align="center">
  <img src="public/images/image%20(1).png" alt="Dashboard Home" width="100%">
</p>

## Features

### Task Management (Todos)
> Create, read, update, and delete tasks.
> Categorize tasks by status (Pending, In Progress, Completed) and priority (Low, Medium, High).
> Assign tasks to specific users.
> Sort and filter tasks efficiently.
> Bulk actions for managing multiple tasks at once.

> View a list of users with their details.
> Add new users and edit existing ones.

# *Tech Stack*

> **Framework:** React
> **Build Tool:** Vite
> **Language:** TypeScript
> **Styling:** Tailwind CSS
> **UI Components:** shadcn/ui (built on Radix UI)
> **Icons:** Lucide React
> **Form Handling:** React Hook Form + Zod
> **Routing:** React Router
> **Animations:** Framer Motion
> **HTTP Client:** Axios (with mock API implementation)
